## What this book is for

This book gives field technicians clear, simple instructions for using ArcGIS Field Maps on the Zebra ET45 to find, download and work through an assigned job. All ET45 tablets are set up before they go out, and the GIS team assigns your jobs to you.

Steps for a particular job type (grid, survey, strategics, testing) are in that job type's book.

## What you need

- [ ] ET45 tablet, fully charged, with Field Maps installed
- [ ] Vehicle charging cable or charger `[CONFIRM]`
- [ ] Your Precision Ag sign-in for Field Maps `[CONFIRM: account type]`
- [ ] Your Deal ID(s), and the job(s) assigned to you
- [ ] A network connection before you leave (office Wi-Fi or a hotspot), to download the job
- [ ] Labelled sample bags, and spares (see your job type's book)

## Words used in this book

| Term | Meaning |
| --- | --- |
| Field Maps | The Esri app on the ET45 used to open jobs, navigate to points and record data |
| Group | A collection of maps in Field Maps, one for each kind of work (for example Field Maps - Grid, Field Maps - Strategic, Precision Ag Testing) |
| Deal ID | The job number. Each job is published under its Deal ID, and you search for it by that number |
| Map areas | The screen that shows which parts of a map are saved on the tablet, and lets you download more |
| Task | One point of work assigned to you |
| Offline | Working with no network, using the job already saved on the tablet |
| Location sharing | Letting Field Maps use the tablet's GPS. It must be turned on each time you open the job |
| GPS accuracy | How closely the tablet knows where it is, in metres. The target is under 5 m |
| My tracks | A layer that draws the path you have travelled |
| Layers | The list of map content you can switch on and off |
| Gate pin | A marker for the easiest way into a paddock |
| Status | Where a point is up to: Unassigned, Assigned, In Progress, Completed or Missed |
