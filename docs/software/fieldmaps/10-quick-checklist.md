# :material-clipboard-check-outline: Quick Checklist

A summary for once you know the full procedure. For first-time steps, use the numbered chapters.

| Stage | Checklist |
| --- | --- |
| Before you leave | - [ ] Tablet charged<br>- [ ] Job found by Deal ID<br>- [ ] Map area downloaded and shown under On device |
| On site | - [ ] Location sharing on<br>- [ ] GPS accuracy under 5 m<br>- [ ] Task list filtered and sorted how you want it<br>- [ ] My tracks on if the work is segmented |
| At each point | - [ ] Bag scanned<br>- [ ] Bag labelled<br>- [ ] Point not reachable: marked Missed with a note |
| At base | - [ ] Connected and sent<br>- [ ] In Progress filter checked<br>- [ ] Supermarket bags rescanned<br>- [ ] Tablet on charge |
