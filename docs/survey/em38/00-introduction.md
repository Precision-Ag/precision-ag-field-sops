# :material-book-open-page-variant: Introduction

Set up the EM38 and Subsoil to run soil survey jobs in the field. This manual is for
Precision Ag field techs.

!!! info "AT A GLANCE"
    Gather the kit, calibrate the EM38, set up the rig, run the survey, then export.
    Exported data reaches the GIS team via SharePoint automatically.

## What this manual covers

This is the field reference for running an EM38 conductivity survey with **Subsoil** on
the Getac.

1. Gather and check your equipment.
2. Calibrate the EM38 (every day, and every time you change location or after four
   hours of continuous operation).
3. Set up the rig on the Polaris or ute.
4. Set up and run the survey in Subsoil on the Getac.
5. Export the data and confirm it has reached the GIS team.
