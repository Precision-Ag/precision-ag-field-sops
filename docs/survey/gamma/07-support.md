## Before you call

Have these ready. It gets you a faster answer.

- [ ] What step were you on? (for example, "Gamma Rig Setup, step 7")
- [ ] What did you expect, and what did you see? (for example, "no green boxes lit")
- [ ] Any Event Log or RadAssist error text
- [ ] Job location (state), so the right GIS inbox can be confirmed
- [ ] The Starlink set up and the Getac connected, so support can get on remotely

    Check [Troubleshooting](06-troubleshooting.md) first. If it doesn't resolve the
    issue, contact Brandon straight away.
