# :material-headset: Support

Who to call when something is not right in the field. Gamma has three separate
contacts, split by the type of issue, use the right one to get a faster answer.

!!! info "AT A GLANCE"

    Peter McMullen (GeoResults).

## Before you call

Have these ready. It gets you a faster answer.

- [ ] What step were you on? (for example, "Gamma Rig Setup, step 8")
- [ ] What did you expect, and what did you see? (for example, "no green boxes lit")
- [ ] Any Event Log or RadAssist error text
- [ ] Job location (state), so the right GIS inbox can be confirmed

!!! note "NOTE"
    Check [Troubleshooting](06-troubleshooting.md) first. If it doesn't resolve the
    issue, contact the right person above straight away.
