# :material-package-variant-closed: Equipment Needed

Before heading out, label your bags and pack against the kit list below.

!!! info "AT A GLANCE"
    Label every bag with grower, paddock, and sample name before you start. Missing a
    label costs you the sample.

## Label all sample bags

Use the large sample bags provided by Nutrient Advantage.

Using Field Maps information, label every bag before you start sampling:

- [ ] Grower name
- [ ] Paddock name
- [ ] Sample name

!!! note "NOTE"
    These details can be found using Field Maps and/or ESRI. If the paddocks and grid
    points do not line up between the apps, contact support.

## Kit list

Make sure you have:

- [ ] **Correct bags** (pictured above)
- [ ] **SalesForce Field Services access**
- [ ] **Esky / fridge**
- [ ] **Icepacks**
- [ ] **Corer** + water for cleaning
- [ ] **Pens / markers**
- [ ] **GNSS / Zebra device**
- [ ] **Boxes & tape**
- [ ] **Field Maps** (app, set up on the Zebra)
- [ ] **Bucket / backpack** for carrying samples
- [ ] **Dig stick** to collect additional surface samples as required

!!! warning "WARNING"
    The only lubricant that can be used in the soil corer is **water**. Chemical
    lubricants affect the analytical results and must be avoided.
