# :material-shovel: Collecting the Soil Sample

**Goal:** collect samples at each sampling point to the defined depth and divide as
accurately as possible into the target depths.

!!! info "AT A GLANCE"
    Core to the required depth, lay it out on the sampling tray, divide by depth, and
    bag. 20mm and 38mm cores are divided differently — see below.

## Steps

1. At each sampling point, collect a core to the required depth (as detailed in Job
   Details in Field Maps).
2. Lay the core out in the sampling tray on the back of the sampling vehicle.

### For 20mm diameter cores

1. Divide the soil core sample at the selected depths using the guidance printed on the
   sampling tray.
2. Place each soil core sample segment into a labelled bucket.

### For 38mm diameter cores

1. Split the soil core sample lengthways.
2. Discard half of the soil core sample.
3. Divide the soil core sample at the selected depths using the guidance printed on the
   sampling tray.
4. Place each soil core sample segment into a labelled bucket.

### Then, for either core size

1. Move to the next point in the transect / zone.
2. Repeat until all samples have been collected, segmented, and divided into buckets.
3. Empty each sample from the labelled bucket into the respective sample bag.
4. The large sample bag should be filled to the "Depth" line, as a minimum.

!!! note "NOTE"
    Where a strategic point sample includes a 0–10cm segment, 4 additional 0–10cm samples
    need to be collected at each sampling point. Using the pogo stick, collect these
    around the vehicle to ensure a spread of samples.

## If you don't have enough soil

If the soil level is below the "Depth" line after 5 cores:

- [ ] Stay within the grid area.
- [ ] Collect additional cores until the bag reaches the line, with a minimum of 10m
      between additional subsamples.
- [ ] Make a note in Field Maps ("Required extra cores for volume").
