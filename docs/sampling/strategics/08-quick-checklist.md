# :material-format-list-checks: Quick Checklist

A one-page summary of the manual. Print it and keep it with your kit.

!!! info "AT A GLANCE"
    Before → During → After. If you can tick every box, the job's done right.

## Before sampling

- [ ] Bags labelled
- [ ] Field Maps open
- [ ] Corer + water
- [ ] Zebra + ESRI
- [ ] PPE, hydration, sunscreen
- [ ] Vehicle parked safely

## During sampling

- [ ] In correct zone
- [ ] Min 5 soil core samples collected
- [ ] Extra cores added if needed
- [ ] Travel across rows
- [ ] Large bag filled to "Depth" line

## After sampling

- [ ] Scanned in ESRI
- [ ] Stored in refrigeration
- [ ] Boxed + counted + sealed
- [ ] TNT Monday–Thursday only
