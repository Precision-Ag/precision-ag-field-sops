# Strategics

*Strategic soil sampling, transects, single-point, and zone-based cores.*

!!! warning "DRAFT, rough pass, not reviewed"
    This manual was populated from the Strategic Sampling Pocket Guide (Rob Allen, 2025)
    as a starting point. It has **not** been checked against current practice and must
    not be used in the field until reviewed and signed off.

This is the field reference for collecting strategic soil samples. Each chapter opens
with an AT A GLANCE box, then the detailed steps.
