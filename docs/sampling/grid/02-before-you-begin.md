# :material-tag-outline: Before You Begin

## Label all sample bags

Using QFields information, label every bag **before** you start sampling. Required
details:

- Grower name
- Paddock name
- Grid zone / point number
- Sample depth

!!! note "NOTE"
    These details can be found using Field Maps and/or ESRI. If the paddocks and grid
    points do not line up between the apps, contact [support](10-support.md).

## Make sure you have

| Item | Item |
| --- | --- |
| Correct sample bags | ESRI access |
| Corer and water for cleaning | Pens/markers |
| GNSS/Zebra device | Boxes and tape |
| Fieldmaps app open | |

!!! danger "IMPORTANT"
    Read all notes and instructions on the job before commencing.
