# :material-ruler: Determining Drill Depth

!!! info "AT A GLANCE"
    Goal: determine Amity settings to collect accurate samples.

1. Check the required depth on the work order.
2. Dig at least 3 pilot holes.
3. Measure the depth of each hole using a tape measure.
4. If required, adjust the position of the depth stopper on the Amity rail.
5. Re-check using at least 3 pilot holes.
