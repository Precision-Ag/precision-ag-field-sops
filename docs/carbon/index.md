# :material-leaf: Carbon

*Soil carbon sampling for AgriProve carbon projects, following AgriProve's OPS006
Soil Sampling Protocol.*

This is the field reference for running a soil carbon sampling round using ArcGIS Field
Maps, Survey123, and QuickCapture. It is a transcription of AgriProve's own OPS006
Standard Operating Procedure (rev 2.3, 08/05/2025) into this site's chapter format, since
this is AgriProve's compliance protocol, not a Precision Ag procedure. Where a step names
an AgriProve role or system (GIS Administrator, Head of Operations, and so on), that is
AgriProve's org, not Precision Ag's. The source PDF is kept at
`docs/carbon/files/agriprove-soil-sampling-protocol-ops006.pdf` for reference.

!!! danger "SWMS"
    This protocol exists to satisfy the Carbon Credits (Carbon Farming Initiative) Act
    2011 and its Method and Supplement. Getting it wrong is not just a data problem, it
    can put an entire project's compliance at risk. See
    [Introduction](00-introduction.md) for the full scope and the regulatory basis.
