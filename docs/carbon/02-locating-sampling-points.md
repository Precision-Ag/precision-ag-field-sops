# :material-map-marker-radius: Locating Sampling Points

Finding and confirming a sampling point correctly is what makes a sample compliant. This
is governed directly by the Supplement, so the accuracy and buffer rules below are not
negotiable.

!!! info "AT A GLANCE"
    GPS accuracy must show less than 1m before you start a sample, and the sample must
    never be taken outside the 4m buffer zone around the target point.

## GNSS accuracy requirement

Part C 1.0(1) of the Supplement requires a GNSS device with a minimum accuracy of +/- 4m
to locate intended sampling locations. Precision Ag field teams currently use an Arrow
100 Series GNSS receiver, which delivers roughly 60cm accuracy. Check with the relevant
AgriProve project manager if you are unsure whether the GPS device you are using meets
this requirement.

## Steps

1. Confirm your GPS system is connected and configured with Field Maps and Survey123 as
   set out in [Equipment and App Setup](01-equipment-and-setup.md).
2. Open Field Maps and select the relevant map. Depending on mobile data coverage, it
   may be preferable to work in an offline map.
3. Your location appears on the map as a small blue circle that moves as you move.
   Target sampling points show with a 4m wide blue buffer zone to help you navigate.
   Get as close as possible to the centre of the buffer zone.

!!! danger "SWMS"
    A sample must never be taken outside the 4m buffer zone around the target point.

4. Before collecting the sample, confirm the GPS accuracy shown at the top of the
   screen in Field Maps is **less than 1m**. Once satisfied, tap the sample point in
   Field Maps, then tap **Start Averaging**. Enter the Field Code shown on the map in
   the `Field_Code` dropdown.
5. Tap the project name and select the relevant Field Code from the dropdown. The
   Survey123 form opens automatically, begin filling it in (see
   [Completing the Survey123 Form](03-survey123-form.md)).

!!! warning "WARNING"
    Also capture the location in Field Maps by tapping the blue circle in the bottom
    right of the screen. This gives data redundancy and traceability alongside the
    Survey123 record.
