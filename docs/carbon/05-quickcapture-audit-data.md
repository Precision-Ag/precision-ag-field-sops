# :material-crosshairs-gps: QuickCapture Audit Data

AgriProve collects additional photos and video in the field to support fully digital
project auditing. This confirms the accuracy of project mapping and gives extra
confirmation of soil core extraction locations. It is collected using ArcGIS
QuickCapture, at locations AgriProve pre-determines for each project.

!!! info "AT A GLANCE"
    Four categories: project boundaries, exclusion zones, a drilling video for the
    first core in each strata, and sample packing photos. Locations show as arrows in
    Field Maps pointing in the required direction of view.

## What to capture

1. Confirmation of project boundaries.
2. Confirmation of exclusion zones.
3. Video of the first core extracted from each project strata.
4. Photographic evidence of sample packing and boxing.

Pre-determined locations for exclusion zones, project boundaries and soil sampling
appear in Field Maps as arrows, pointing in the direction the photo or video should be
taken.

## Exclusion zones

1. Navigate to the pre-determined location in Field Maps.
2. Open QuickCapture and enter the project name at the top of the screen.
3. Tap **Exclusion Type** and select the type matching the label in Field Maps, then
   photograph the exclusion zone.

!!! warning "WARNING"
    Take the exclusion zone photo from approximately 10m away from its boundary,
    looking toward the excluded area. Use the widest camera angle available to capture
    as much of the excluded area as possible.

## Project boundaries

4. Tap the boundary button matching the corner you have navigated to (NW, NE, SW, SE),
   then photograph the boundary.

!!! warning "WARNING"
    Take the boundary photo from approximately 20m away from the boundary, looking
    toward it. Use the widest camera angle available to capture as much of the boundary
    as possible.

## First core video, per strata

5. For the first core extracted in each strata, record a short video of the location
   using the **Sample Drilling** button. QuickCapture only allows 10 seconds, so make
   it a 360 degree view of the location, including the sampling rig. **Core Length** is
   not required.

## Packing evidence

6. Use **Bagging** to photograph the stored sample bags for the project, with some
   field codes visible where possible. Use **Boxing** to photograph the packed boxes
   before dispatch.

!!! note "NOTE"
    Bagging and boxing photos do not need a GNSS fix, so they can be taken later if
    needed.

There is no manual sync step, QuickCapture data uploads automatically once a data
connection is available.
